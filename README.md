# The Town With No Name — нативный порт (Windows / Linux)

Это замена `TOWN\DTVPLAY.EXE` — DOS-плеера «шотов» с PC CD-ROM версии игры.
Сама игра целиком описана данными на диске: сценарии (`FORM DTV3` и старый `VER2SHOT`),
картинки IFF ILBM (включая HAM6 и interlace), анимации IFF ANIM (op 5), звуки 8SVX/raw и
музыка в VOC. Плеер был восстановлен по дизассемблированному `DTVPLAY.EXE` и переписан на
C + SDL2, поэтому игре больше не нужен DOS/DOSBox. Файлы игры не изменяются.

## Запуск

Положите `townplay` (Linux) или `townplay.exe` (Windows) в корень диска — туда, где лежат
`STARTSHOT` и папка `TOWN` — и запустите. Также плеер сам находит данные, если он лежит
в `native/dist/<платформа>/` внутри папки диска, или можно указать путь явно:

```
townplay --data /путь/к/CDTOWN
townplay --lang french          # english, french, german, spanish, italian, danish
townplay --fullscreen
townplay --square               # квадратные пиксели, целочисленное масштабирование
```

Изображение масштабируется без сглаживания (nearest neighbour). По умолчанию картинка
растягивается до 4:3, как на мониторах того времени; при этом строки получаются чуть
разной высоты. Для идеально ровных пикселей используйте `--square`.

Все опции: `townplay --help`.

### Управление

| Действие | Клавиши |
|---|---|
| Кнопка A (выбор) | левая кнопка мыши, `A`, `F1`, `+` на цифровом блоке |
| Кнопка B (назад) | правая кнопка мыши, `B`, `F2`, `-` на цифровом блоке |
| Двигать указатель | мышь, стрелки, цифровой блок |
| Полноэкранный режим | `F11` или `Alt+Enter` |
| Скриншот (PNG) | `F12` |
| Выход | `Ctrl+Esc` или закрыть окно |

### CD-audio (речь персонажей)

Почти все диалоги и часть музыки — это аудиодорожки CD: сценарии содержат 180 команд
проигрывания фрагментов дорожек 2 (~19 минут) и 3 (~15 минут). Это не файлы, при
копировании диска как папки они теряются.
В этой копии диска есть только файлы, поэтому без образа игра проходится, но в этих местах
молчит; тайминг сцен от этого не зависит. Если у вас есть полный образ диска в виде `.cue`
с `.bin` (или WAV на каждую дорожку), укажите его:

```
townplay --cd /путь/к/town.cue
```

или положите его рядом с данными под именем `town.cue` — тогда он подхватится сам.

## Сборка

### Linux

Нужны компилятор C, CMake и пакет разработки SDL2 (`libsdl2-dev` / `sdl2`):

```
./build-linux.sh          # -> dist/linux/townplay
```

### Windows

Кросс-сборка из Linux (скрипт сам скачает zig и официальный SDL2 для MinGW в `.deps/`):

```
./build-windows.sh        # -> dist/windows/townplay.exe (один файл, SDL2 вкомпилирован)
```

Нативно на Windows: CMake + Visual Studio или MinGW и пакет SDL2 (например, через vcpkg:
`vcpkg install sdl2`), затем `cmake -S . -B build && cmake --build build --config Release`.

## Что было восстановлено из DTVPLAY.EXE

- Формат шотов `DTV3`: `GRPH` (картинка, 3 языковых оверлея, переход, число циклов,
  длина цикла, fps), `INPT`, `CAUD` (звук), `CDTV` (трек и MSF-диапазон CD),
  `EVNT` (триггер: кнопка A по полигону `BPNT`, кнопка B, клавиши, таймер в
  секундах/десятых), `AVNE` (переход: goto / gosub `^` / return / quit, вес),
  `AFRM` (маска кадров анимации, в которых переход доступен). Чанки без выравнивания.
- Формат `VER2SHOT` (`SCNF`, `BACK`, `ANMC`, `CDTV`) для 47 старых шотов.
- Выбор перехода — взвешенный случайный по маске текущего кадра, с тем же генератором
  `seed = (seed*13 + 19) mod 10001`, что и в оригинале.
- Таймеры 72 Гц, тайминг анимации (по умолчанию 7 тиков на кадр), упреждающее
  декодирование кадров в двойной буфер, циклы анимации и счётчик кадров для масок.
- Попадание в хотспот — тот же алгоритм пересечений луча, что в оригинале.
- Переходы между шотами — затухание/проявление палитры по 64 шагам, как на VGA.
- Резолвер имён: `DUNE:`/`DTV:`/`LANGUAGE_DIR:` и таблицы `FILES.MAP`, `FILES.TRN`,
  `MUSIC.SUB` из папки `TOWN` (PC-версии файлов имеют приоритет, как в DOS-версии).
- Звук: 8SVX и raw-сэмплы с повторами, VOC с Creative ADPCM 4 / 2.6 / 2 бита и блоками
  повтора, команды CD-audio.

## Отличия от DOS-версии

- Картинки выводятся в truecolor: HAM6 и 640×512 показываются без квантизации до VGA,
  interlace-картинки — со всеми 400 строками.
- Из музыки VOC убрана инфразвуковая постоянная составляющая, которую даёт 2.6-битный ADPCM.
- Ссылка на отсутствующий `DUNE:TTWNN/gun2` (ошибка в данных диска) находит `OUT/GUN2`.
- Запуск внешних программ из сценария (`!prog`) не поддерживается; в достижимых шотах
  он не используется.

## Отладка

```
townplay --trace                          # печатать каждую смену шота
townplay --start DUNE:OUT/Shot0.01        # начать с конкретного шота (въезд в город)
townplay --autoplay                       # сам кликает по случайным хотспотам
townplay --screenshot out.png --run-ms 5000 --autoplay --seed 3   # без окна, для тестов
```
